# Система анализа речи и интервью

## Описание проекта

Это система для комплексного анализа аудио- и видеоинтервью, которая автоматически транскрибирует речь, разделяет диалоги по спикерам и проводит лингвистический анализ текста. Реализована работа только с русским языком.

## Основные возможности

- **Автоматическая транскрипция** аудио- и видеофайлов с помощью модели Whisper
- **Диаризация речи** - автоматическое разделение диалога по спикерам
- **Лингвистический анализ** с вычислением различных индексов читаемости и сложности текста
- **Семантический анализ** с категоризацией лексики по тематическим группам
- **Распознавание паттернов** в речи (модальные конструкции, пассивные выражения, активные глаголы)

## Используемые технологии

### Обработка аудио и речи
- **OpenAI Whisper** - для транскрипции аудио в текст
- **pyannote.audio** - для диаризации речи (разделения по спикерам)

### Обработка естественного языка
- **spaCy** - основная библиотека для NLP-анализа
- **pymorphy3** - морфологический анализатор русского языка

## Требования к системе

- Python 3.8+
- CUDA-совместимая видеокарта
- Минимум 8 ГБ оперативной памяти
- Свободное место на диске для локальных моделей (~3-4 ГБ)
- Наличие pyannote-audio3.1
- Наличие ffmpeg
